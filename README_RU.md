# Stars New Skills All-in-One — русская локализация

Эта ветка содержит русифицированную копию `Stars New Skills All-in-One.sml` для набора Stars под Stoneshard 0.9.4.24.

## Что переводится

Русский язык добавляется непосредственно во встроенные таблицы локализации мода. Игровая логика, GML-код, ресурсы, числовые значения, цветовые теги и placeholders не меняются.

Покрыто:
- дерево **Некромантия**;
- **Аура нежизни**;
- **Жуткое откровение** и его эффект;
- **Эдикт Хелы**;
- **Ко мне, фанатики!**;
- деревья магии/боя/даров Проселитов;
- все 40 добавленных модом боевых реплик (вымышленные заклинательные формулы сохранены без перевода, осмысленные фразы переведены).

## Установка

Используйте файл:

`dist/Stars New Skills All-in-One.sml`

вместо оригинального `Stars New Skills All-in-One.sml`.

Остальные два файла набора остаются исходными:

1. `0_Stars Overhaul.sml`
2. `Stars Enemy Enhancing.sml`
3. `Stars New Skills All-in-One.sml` — русифицированная версия из `dist`

Порядок важен. Не переименовывайте эти три файла.

Перед компиляцией через MSL рекомендуется восстановить чистый `data.win` через проверку файлов Steam.

## Техническая проверка

Патчер:
- работает с контейнером MSLM v0.13.2.0;
- изменяет только embedded .NET assembly;
- добавляет `ModLanguage.Russian = 0` в 49 локализационных объектов;
- ожидает и проверяет 58 русских dictionary entries;
- повторно открывает пропатченную assembly через Mono.Cecil и валидирует наличие русских ключей;
- не перезаписывает исходный SML.
